# Resume Skill Analyzer

A beginner-friendly Python project that compares a candidate's skills with the skills required for a job and calculates a skill match percentage.

## Features

- Compares candidate skills with required skills
- Identifies matched skills
- Identifies missing skills
- Calculates the overall match percentage
- Displays the analysis in a simple format

## Technologies Used

- Python
- Lists
- Sets
- Conditional Statements
- For Loops
- Basic Python Functions and Operations

## Example

### Required Skills

- Java
- AWS
- Docker
- FastAPI
- Python

### Candidate Skills

- Python
- SQL
- Docker
- Java

### Result

- Matched: Java, Docker, Python
- Missing: AWS, FastAPI
- Match Score: 60%
